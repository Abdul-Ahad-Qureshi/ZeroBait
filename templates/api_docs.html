Core Endpoints

POST /predict Rate Limit: 40/min

Analyzes a single URL, extracting 22 lexical features, DNS/MX intel, and outputs a threat score (0-100%).

// Request Payload: { "url": "https://example-security-update.xyz/login" } // Response JSON (200 OK): { "url": "https://example-security-update.xyz/login", "score": 88.5, "threat_level": "High", "is_malicious": true, "flags": [ { "label": "Suspicious TLD: .xyz", "points": 20 }, { "label": "Phishing keywords: login", "points": 20 } ] }
GET /api/ioc/export?format=stix Public Feed

Exports active high-confidence indicators of compromise in STIX 2.1 JSON, CSV, or Plaintext firewall format.

Code Samples

Python SDK (requests)

import requests def inspect_url(target_url): response = requests.post( "http://127.0.0.1:8000/predict", json={"url": target_url}, timeout=5.0 ) result = response.json() print(f"URL: {result['url']} | Score: {result['score']}% ({result['threat_level']})") return result inspect_url("https://paypal-update.xyz/signin")

cURL Terminal Command

curl -X POST "http://127.0.0.1:8000/predict" \ -H "Content-Type: application/json" \ -d '{"url": "https://suspicious-site.top/verify"}'
